# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Hugo uses this local Console to inspect and operate his existing company/personal brain. Other audiences are not established by this redesign.

## Product Purpose

Make the state of the brain, Systems, Sources, routines, executions, notices, judgments and existing measurements inspectable from their canonical local evidence.

## Operating Context

The Node Console engine and the selected data vault may live in different directories. The current interface includes workspaces, G6 Canvas, private detail drawers, keyboard navigation and source opening. An installed package must run without client-side installation or build.

## Capabilities and Constraints

Preserve engine APIs, data-root selection, session and CSRF protections, strict CSP, local fonts/assets, privacy gates, explicit human judgments and existing workspace behavior. No business values or execution evidence may be invented. Design QA uses synthetic fixtures.

## Stack

Existing Node ES-module engine and G6 Canvas. Hugo explicitly approved migrating the interface to React + genuine shadcn/ui; domain services and APIs remain in place.

## Brand Commitments

Hugo selected the established visual identity of ~/projects/task-manager as reference and requires a centralized design system without scattered hardcoded visual values.

## Product Principles

- Canonical sources and receipts establish state; the interface is a derived view.
- Opening private detail and changing judgment are explicit actions.
- Shared tokens and components keep all workspaces consistent.
- Keyboard, mobile and reduced-motion behavior are part of the product.
