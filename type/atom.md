# Atom

Átomo: uma nota de uma ideia só, com afirmação (o H1), evidência literal entre aspas, sentido e elos. Vive no horizonte certo de `meu-negocio/` (fios, áreas, decisões). Sem evidência, não é átomo.

Campos: `topic`, `created`, `confirmed`, `origin` (wikilink entre aspas para a fonte) e `related_to` para os elos.

Quando outra nota o substitui, recebe `status: Superseded` com `superseded_by`.
